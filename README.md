# 買房決策工具箱｜A＋C 視覺版

「學校學不到的事」首購族免費互動練習室。以看屋前、看屋中、看屋後三個階段為主軸，分為六章，提供十二個簡易工具、六張互動檢核卡與六個章節知識圖解區。

## 如何預覽

網站全部整合在根目錄的 `index.html`，無需安裝或建置。可直接下載後用瀏覽器開啟。

## GitHub Pages 發布

1. 前往倉庫 **Settings → Pages**。
2. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**。
3. **Branch:** `main`；**Folder:** `/(root)`；按 **Save**。
4. 網址預期為 https://0point38.github.io/home-buying-toolkit/ （需先成功啟用 Pages 才有效）。

## 後續維護

- 網站內容與互動皆在 `index.html`，可直接交給 Codex 修改。
- 修改工具時，請只動指定工具，保留既有 18 張卡片、三階段及知識補充內容。
- 修改後預覽手機與桌面版本，並檢查試算、篩選與清單功能。

> 本站為教育用途，試算結果與談價推估非銀行授信承諾、專業估價或法律建議。
